# What's Cookin

Type in what's already in your kitchen, and find real recipes you can actually make — missing an ingredient or two? We'll tell you, and suggest a substitute.

Built with React, Vite, Tailwind CSS, and Supabase. Recipe data via TheMealDB.

## Tech Stack
- React + Vite
- Tailwind CSS v4
- Supabase (favourites storage)
- TheMealDB API

## Getting Started
\`\`\`bash
npm install
npm run dev
\`\`\`
